개인정보처리방침 (Privacy Policy)

시행일: 2026년 11월 10일 · 앱: 물음표 동물원 업로더 (Mureumpyo Zoo Uploader)

1. 앱 소개

이 앱은 유튜브 채널 「물음표 동물원」(@mureumpyo_zoo) 운영자 본인만 사용하는 개인용 데스크톱 프로그램으로, 운영자가 직접 제작한 쇼츠 영상과 썸네일을 운영자 본인의 채널에 업로드합니다. 다른 사용자에게 제공되지 않습니다.

2. 사용하는 Google 데이터

  • YouTube 업로드 권한 (youtube.upload): 운영자 채널에 영상·썸네일 업로드, 공개 예약 설정
  • YouTube 읽기 권한 (youtube.readonly): 운영자 채널의 영상 조회수·좋아요 등 공개 통계 확인

이 외의 Google 계정 정보(이메일, 연락처, 다른 사용자의 데이터 등)는 요청하거나 수집하지 않습니다.

3. 데이터 저장과 공유

  • 로그인 토큰과 영상 통계는 운영자 본인의 PC에만 저장되며, 외부 서버로 전송하지 않습니다.
  • 어떠한 데이터도 제3자에게 판매·공유하거나 광고 목적으로 사용하지 않습니다.
  • Google API 서비스에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.

4. 권한 철회와 데이터 삭제

Google 계정 → 보안 → 타사 앱 액세스에서 언제든 이 앱의 권한을 철회할 수 있습니다. 운영자 PC에 저장된 토큰 파일(token.json)을 삭제하면 로컬 데이터도 모두 삭제됩니다.

5. YouTube 서비스 약관

이 앱은 YouTube API 서비스를 사용하며, 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침의 적용을 받습니다.
